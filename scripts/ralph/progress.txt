## Codebase Patterns
- Database operations must use DatabaseService's serial queue `com.englishai.database`
- UI updates must be on main thread via `DispatchQueue.main.async`
- Models are defined in `EnglishAI/Models/` folder and must be added to project.pbxproj
- DatabaseService uses raw SQLite3 with prepared statements (no ORM)
- Date storage uses ISO8601 format for TEXT columns, timeIntervalSince1970 for REAL columns
- Services are singletons accessed via `.shared`
- When adding new Swift files, must add to project.pbxproj in 4 places: PBXBuildFile, PBXFileReference, PBXGroup, PBXSourcesBuildPhase
- Unique IDs in project.pbxproj follow pattern: B1000001226A000X0000YYY - increment YYY for new files
- macOS does NOT use AVAudioSession (iOS only) - AVAudioRecorder works directly without session configuration

## 2026-01-19 - US-005

  - Added `WhisperTranscriptionError` enum with descriptive errors (noAPIKey, fileNotFound, fileTooLarge, networkError, invalidResponse, rateLimited, apiError)
  - Implemented `transcribe(audioFilePath:)` async method that:

  - Uses endpoint: POST https://api.openai.com/v1/audio/transcriptions
- Files changed:
  - EnglishAI/Services/WhisperTranscriptionService.swift (new)
  - EnglishAI.xcodeproj/project.pbxproj (modified)

  - Whisper API has 25MB file size limit - US-006 will handle chunking for larger files

## 2026-01-19 - US-006
- What was implemented:
  - Added `chunkingFailed(String)` error case to `WhisperTranscriptionError`
  - Added `targetChunkSizeBytes` constant (20MB) to keep chunks safely under 25MB API limit
  - Implemented `transcribeWithChunking()` method that:
    - Loads audio asset duration using AVAsset async API
    - Calculates chunk duration based on bytes-per-second ratio
    - Creates temporary directory for chunk files
    - Uses `defer` to ensure cleanup even on error
    - Splits audio using AVAssetExportSession with AVAssetExportPresetAppleM4A preset
    - Transcribes each chunk sequentially
    - Concatenates transcriptions with space separator
  - Refactored `transcribe()` to call `transcribeSingleFile()` for small files or `transcribeWithChunking()` for large files
  - Added `exportAudioChunk()` helper using AVAssetExportSession with time range
  - Added `cleanupChunkFiles()` helper to remove temporary directory
- Files changed:
  - EnglishAI/Services/WhisperTranscriptionService.swift (modified)
- **Learnings for future iterations:**
  - Use AVAsset async load API: `try await asset.load(.duration)` instead of deprecated synchronous `duration` property
  - AVAssetExportSession with preset `AVAssetExportPresetAppleM4A` produces M4A files compatible with Whisper API
  - CMTime operations: `CMTimeGetSeconds()` for conversion, `CMTime(seconds:preferredTimescale:)` for creation
  - Use `defer` block for cleanup to ensure it runs regardless of success/failure
