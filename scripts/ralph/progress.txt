## Codebase Patterns
- Database tables are created in `DatabaseService.createTables()` using `CREATE TABLE IF NOT EXISTS`
- All tables use the same SQL string executed in one `sqlite3_exec` call
- Use TEXT for dates (ISO8601 format) for compatibility with existing tables
- Foreign keys use `ON DELETE CASCADE` where appropriate
- Table naming: snake_case for columns, camelCase for Swift model properties
- Indexes: create on foreign keys and frequently queried columns
- Models: use Identifiable + Codable, optional Int64 id, init with defaults
- Adding Swift files: update 4 sections in project.pbxproj (PBXBuildFile, PBXFileReference, PBXGroup children, PBXSourcesBuildPhase files)
- JSON-stored content: use custom Codable with "type" + "content" pattern for discriminated unions
- Exercise views: use callback pattern `onComplete: (Bool, String, Int) -> Void` for (isCorrect, feedback, timeSpentSeconds)
- AI API calls: use AIAnalysisService.shared for API key access; parse JSON responses handling markdown code blocks
- FlowLayout: custom SwiftUI Layout in ErrorCorrectionExerciseView.swift for word wrapping - reusable for draggable tiles
- Weakness progress tracking: ExerciseAttemptData.saveToDatabase() updates both attempt and WeaknessProgress
- Spaced repetition: masteryLevel thresholds determine nextReviewDate intervals (1/3/7/14/30 days)
