## Codebase Patterns
- Database operations must use DatabaseService's serial queue `com.englishai.database`
- UI updates must be on main thread via `DispatchQueue.main.async`
- Models are defined in `EnglishAI/Models/` folder and must be added to project.pbxproj
- DatabaseService uses raw SQLite3 with prepared statements (no ORM)
- Date storage uses ISO8601 format for TEXT columns, timeIntervalSince1970 for REAL columns
- Services are singletons accessed via `.shared`
- When adding new Swift files, must add to project.pbxproj in 4 places: PBXBuildFile, PBXFileReference, PBXGroup, PBXSourcesBuildPhase
- Unique IDs in project.pbxproj follow pattern: B1000001226A000X0000YYY - increment YYY for new files
- macOS does NOT use AVAudioSession (iOS only) - AVAudioRecorder works directly without session configuration
